# hal-layer — P15 HAL

README.md — repository purpose and layer contract for P15 HAL.

Function:
    This repository implements primitive layer P15 of the Forge Stack:
    the Human Accountability Layer. It enforces the five-tier ladder,
    applies quarantine below λ = 0.60, and generates signed seals for
    every human validation, including refusals.
